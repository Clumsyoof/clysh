## About The Project

A custom unix shell implementation based on Stephen Brennan's LSH shell 
<p align="right">(<a href="#readme-top">back to top</a>)</p>

<!-- GETTING STARTED -->
## Getting Started

### Prerequisites

This project is built for Unix machines running bash.

You will need the following build tools:
*`gcc`
*`CMake`

### Installation

1. Clone the repository and navigate into it.
2. Run the installer:
   ```
   ./install.sh
   ```
<!-- USAGE EXAMPLES -->
## Usage

Once installed,launch the shell using clysh.

````
clysh
````

Type help for further usage.
